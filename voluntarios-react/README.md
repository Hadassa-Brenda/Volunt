# Voluntá+ React

Projeto React organizado com CSS puro, componentes separados e sem Vite.

## Como rodar

```bash
npm install
npm start
```

O projeto usa `react-scripts`, então o comando de desenvolvimento é `npm start`.

## Estrutura principal

```txt
src/
  app/
  assets/
  components/
  constants/
  data/
  styles/
  utils/
```

Cada componente possui sua própria pasta com `.jsx` e `.css`.
